# BIU Lost and Found

A mobile application built for BELTEI International University (BIU) students and staff to report, search, and recover lost or found items on campus.

## Overview

BIU Lost and Found addresses the common problem of misplaced belongings within a university setting by providing a centralized, easy-to-use platform where community members can:
- Report items they've lost
- Report items they've found
- Browse and search reported items to find matches
- Contact the reporter to arrange item return

## Problem Statement

Lost items on campus (ID cards, phones, wallets, bags, textbooks) are often reported through informal channels — Telegram groups, word of mouth, or physical notice boards — which are slow, disorganized, and easy to miss. This app centralizes lost and found reporting into a single, searchable system accessible to all BIU students.

## Key Features

- **Report Lost Item** — submit item details, description, category, location, and date lost
- **Report Found Item** — submit details of an item found on campus
- **Browse & Search** — filter items by category, location, or date to find matches
- **Item Details View** — view full details and reporter contact info
